\section{Hyper-parameters and their sources}
\label{app:hyper}

\paragraph{Rule for choosing values.} We applied a fixed order of precedence:
\begin{enumerate}
  \item The benchmark paper of Papoudakis et al.~\citep{test} (arXiv:2006.07869v4).
  \item Otherwise, the algorithm's own paper.
  \item Otherwise, the authors' public code.
  \item Only then our own judgment, marked \textbf{(ours)} below.
\end{enumerate}
No grid search was performed for any algorithm.

\paragraph{Source keys used in the tables.}
\begin{itemize}
  \item \textbf{[B]} Papoudakis et al.~\citep{test}, v4: Sec.~4 for the protocol, Appendix~I for
        the LBF values selected by their grid search with parameter sharing (Table~28 for QMIX,
        Table~24 for MAPPO).
  \item \textbf{[E]} EPyMARL, the code released with [B], for structural details [B] does not
        state.
  \item \textbf{[Q]} QPLEX paper~\citep{wang2021qplex}.
  \item \textbf{[M]} MACPF paper~\citep{macpf}, Appendices C and E.
  \item \textbf{[Mc]} MACPF authors' PyMARL-based code (\texttt{dfop.yaml}).
  \item \textbf{[A]} ATD paper~\citep{deng2026adaptive}, Sec.~4, Table~3, Algorithm~1.
  \item \textbf{[Y]} MAPPO paper~\citep{yu2022mappo}.
\end{itemize}

\paragraph{Item levels.} The benchmark ran lbforaging~1.0.x. Let $S$ be the sum of the three
lowest agent levels.
\begin{itemize}
  \item Version~1 draws a non-cooperative item's level from $\{1,\dots,S-1\}$
        (\texttt{randint(1,S)}).
  \item Version~2.0.0 draws it from $\{1,\dots,S\}$. With three agents, this raises the share of
        items only all agents together can load from about 2\% to about 25\%.
  \item Cooperative items have level $S$ in both versions, so the two \texttt{-c} tasks are
        unaffected.
\end{itemize}
We restore version~1's rule. Our first seed under version~2 was far below the benchmark on the
non-cooperative tasks: MAPPO scored 0.12 vs.\ 0.77 on 15x15-3p-5f. Those runs are excluded.

\paragraph{QPLEX note.} The benchmark does not include QPLEX, so its mixer comes from its own paper.
QPLEX's own training settings ([Q], App.~B.2) are the PyMARL defaults:
\begin{itemize}
  \item $\epsilon$ annealed over 50k steps;
  \item RMSprop with learning rate $5\times10^{-4}$;
  \item two updates per episode;
  \item a hard target update every 200 episodes.
\end{itemize}
With these settings it never rose above a return of 0 on LBF: 0.00 after 700k steps on
8x8-2p-2f-c, where QMIX had 0.42 by 1M. By the project's decision, QPLEX therefore uses QMIX's
benchmark-tuned LBF settings, so QMIX and QPLEX differ only in the mixer.

\paragraph{Why the fixed-$\lambda$ controls exist.} Base QMIX and QPLEX use 1-step targets and
base MAPPO uses 5-step targets. ATD therefore changes two things at once: it introduces
$\lambda$-returns, and it adapts $\lambda$ per state-action pair. The controls isolate the
second change.
